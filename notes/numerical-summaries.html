Measures of Location
Mean (Average): most commonly used measure of central location
Sample Mean: $\bar{x}=\dfrac{\sum{x}}{n}$, Population Mean: $\mu=\dfrac{\sum{x}}{N}$
Median: measure of central location that's useful with extreme values
1. Arrange the data in ascending order
2a. If there are an odd number of values, take the middle value
2b. If there are an even number of values, average the two middle values
Mode: most common value, Bimodal: 2 modes, Multi-Modal: more than 2 modes
Percentiles: at least p% of the data is less than the pth percentile
1. Arrange the data in ascending order
2. Calculate the index: $i = \left(\dfrac{p}{100}\right)n$
3a. If the index is not an integer, round up and take the value in that position
3b. If the index is an integer, average the values in position i and i+1
Quartiles: $Q_1$ = 25th percentile, $Q_2$ = 50th percentile, $Q_3$ = 75th percentile

Measures of Variability
Range: simplest measure of variability, Range = Largest Value - Smallest Value
Interquartile Range: measure of variability that's useful with extreme values, IQR = $Q_3 - Q_1$
Variance: measure of variability that uses all the data
Sample Variance: $s^2=\dfrac{\sum{(x-\bar{x})^2}}{n-1}$, Population Mean: $\sigma^2=\dfrac{\sum{x}}{N}$
Standard Deviation: measure of variability that's in the same units as the data
Sample Standard Deviation: $s = \sqrt{s^2}$, Population Standard Deviation: $\sigma = \sqrt{\sigma^2}$

Measures of Relative Location
Skewness: measure of distribution shape (-, 0, +)
z-Scores: measure of relative location, IQR = $Q_3 - Q_1$
Variance: measure of variability that uses all the data
Sample Variance: $s^2=\dfrac{\sum{(x-\bar{x})^2}}{n-1}$, Population Mean: $\sigma^2=\dfrac{\sum{x}}{N}$
Standard Deviation: measure of variability that's in the same units as the data
Sample Standard Deviation: $s = \sqrt{s^2}$, Population Standard Deviation: $\sigma = \sqrt{\sigma^2}$
