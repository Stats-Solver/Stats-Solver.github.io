Hypothesis Testing in R

Rejection Rule

Two-Tailed Test
Formula:

$$ \text{Reject } H_0 \text{ if } z \leq -z_{\alpha / 2} \text{ or if } z \geq z_{\alpha / 2} $$

Example:

$$ z = -2.74 $$

$$ \text{Critical Values:} $$

$$ -z_{\alpha / 2} = -1.96 \text{ and } z_{\alpha / 2} = 1.96 $$

Functions:

if (condition) {output1} else {output2}

Explanation:

The rejection rule for the critical value says to reject the null hypothes if the test statistics is less than or equal to the negative critical value or if it is greater than or equal to the positive critical value.
