Mean

$\bar{x}=\dfrac{\sum{x}}{n} $


Median

Median

If the number of observations (n) is odd: the median is the middle value, which is at position

$\dfrac{({n+1})}{2} $

If even: the median is the average of the two middle values.

$\frac{1}{2}(\dfrac{{n}}{2} + ({\dfrac{{n}}{2}+ 1)}) $

Mean Mode

Mode

Mode: The value in the data set that occurs most frequently.

Percentiles

$i = (\frac{p}{100})n $

Step 1. Arrange the data in ascending order (smallest value to largest value).

Step 2. Compute an index (i) where p is the percentile of interest and n is the number of observations.

Step 3. (a) If i is not an integer, round up. The next integer greater than i denotes the position of the pth percentile. (b) If i is an integer, the pth percentile is the average of the values in positions i and i + 1.

Quartiles

$i = (\frac{p}{100})n $

Q1 = first quartile or 25th percentile

Q2 = second quartile or 50th percentile (also the median)

Q3 = third quartile or 75th percentile

Range

Range = Largest value - Smallest value

Interquartile Range

IQR = Q3 - Q1

Variance

$s^2=\dfrac{\sum({x_i-\bar{x})^2}}{n-1} $

Standard Deviation

Sample Standard Deviation = $s = \sqrt{s^2}$

Z-Score

$z = \frac{x - \mu}{\sigma}$

Covariance

Sample Covariance: $s_{xy} = \dfrac{\sum({x_i-\bar{x})(y_i-\bar{y})}}{n-1}$

Correlation Coefficient

$r_{xy} = \frac{s_{xy}}{s_{x}s_{y}}$

where

$r_{xy}$ = sample correlation coefficient

$s_{xy}$ = sample covariance

$s_x$ = sample standard deviation of x

$s_y$ = sample standard deviation of y
