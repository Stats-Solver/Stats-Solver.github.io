Hypothesis Testing in R

Introduction:

In hypothesis testing, we are trying to test an assumption about the value of a population parameter, such as the population mean ($\mu$). In hypothesis tests about the population mean, there are two cases. The first case is when the population standard deviation ($\sigma$) is known and the other case is when the population standard deviationn is unknown. Then there are three forms of a hypothesis test: lower tail, upper tail and two-tailed.

Lower Tail Test Upper Tail Test Two-Tailed Test
$H_0 \colon \mu \geq \mu_0$ $H_0 \colon \mu \leq \mu_0$ $H_0 \colon \mu = \mu_0$
$H_a \colon \mu < \mu_0$ $H_a \colon \mu > \mu_0$ $H_a \colon \mu \neq \mu_0$

The first step in a hypothesis test, of any case or form, is to calculate the test statistic. The formula for the test statistic will dependent on whether $\sigma$ is known or unknown. If $\sigma$ is known, then the test statistic is written as $z$. This is because the test statistic in the $\sigma$ known case follows the standard normal, or z, distribution. In the $\sigma$ unknown case, the test statistic is written $t$ because it follows a $t$ distribution with $n-1$ degrees of freedom. Computing this formulas in R requires only one function to compute the square root. The function for calculating the square root in R is sqrt(x).

$\sigma$ Known $\sigma$ Unknown
Test Statistic $ z = \dfrac{\bar{x}-\mu_0}{\sigma/\sqrt{n}} $ $ t = \dfrac{\bar{x}-\mu_0}{s/\sqrt{n}} $

Once the test statistic is calculated, it can be used to calculate a probability known as a p-value. In a lower tail test, the p-value is the probability of getting a value for the test statistic as small as or smaller than the value from the sample. Since the test statistic follows a standard normal (z) distribution, the p-value is the area to the left of the test statistic under the z distribution. In R, probabilities for a normal distribution can be computed using the pnorm(q) function. The default values for the mean and standard deviation of this function are 0 and 1, corresponding to the standard normal distribution.


After the p-value is computed, we can use the rejection rule for the p-value to determine whether or not to reject the null hypothesis ($H_0$). The rejection rule for the p-value says that we reject the null hypothesis if the p-value is less than or equal to the level of significance ($\alpha$). Coding this in R requires the use of an if-else statement. That is, one code is executed if a condition is satisified and a different code is executed if the condition is not satisifed.

Lower, Upper and Two-Tailed
if (pvalue <= alpha) {
   "reject null"
} else {
   "don't reject null"
}

Another way to conduct a hypothesis test is to use a critical value. For a lower tail test, the critical value is the value of the test statistic corresponding to an area of $\alpha$ in the lower tail of the sampling distribution of the test statistic. Since the test statistic follows the standard normal ($z$) distribution, the critical value is the z value corresponding to an area of $\alpha$ in the lower tail of the $z$ distribution. For a lower tail test when $\sigma$ is known, the critical value is written $-z_\alpha$. The R function qnorm(p) can be used to calculate the critical value.

Just as there is a rejection rule for the p-value, there is a rejection rule for the critical value. The rejection rule for the critical value says to rejection the null hypothesis ($H_0$) if the test statistic ($z$) is less than or equal to the critical value ($-z_\alpha$). Like the rejection rule for the p-value, we will have to use an if-else statement to code this in R. If the condition for the critical value is satisfied we will reject the null hypothesis, otherwise we will not reject the null hypothesis.
