Introduction:

The first step in simple linear regression is to get the estimated regression equation: $\hat{y}=b_0+b_1x$. This involves the computation of the two main componennts of the equation, the slope ($b_1$) and the intercept ($b_0$). The slope is typically computed before the intercept because the formula for the intercept includes the slope. This formula for the slope is complicated and the R code for it is complicated as well. The values are then filled in using a for loop and those values are summed using the sum() function.

Slope Intercept
$$ b_1=\dfrac{\sum (x_i-\bar{x}) (y_i-\bar{y})}{\sum (x_i-\bar{x})^2} $$ $$ b_0=\bar{y} - b_1 \bar{x} $$

After the estimated regression equation, the coefficient of determination is the most important part of regression. Computation of the coefficient of determination involves calculating a set of statistics known as sum of squares. The first step in computing the sum of squares is to calculate the predicted values. The predicted values are simply the values for the estimated regression equation ($\hat{y}_i=b_0+b_1x_i$) when the different values of $x$ are plugged in. Since there are multiple $x$ values, we have to use another for loop to compute the predicted values.

for (i in 1:n) {
   XY[i] <- (x[i] - mean(x)) * (y[i] - mean(y))
   X2[i] <- (x[i] - mean(x)) ^ 2
}
