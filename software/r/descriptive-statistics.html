Descriptive Statistics in R

To calculate the mean, or average, simply use the mean() function. There is only one argument that goes into this function, the data. So first input your data using c() and assign it to a variable such as x using an assignment <- . To calculate the median, simply use the median() function and put your variable x as the argument like before. There is no function for the mode, however, the table() function can help you to quickly find it. The function for calculating percentiles is quantile(). However, unlike the previous statistics, there are two arguments needed for this function. The first argument is the data and the second is the percentile you want, written as a decimal. So for example, if you want the 75th percentile, input it as .75. Since quartiles just refers to some specific percentiles, you can use the same function you used to calculate percentiles.

mean(x)
median(x)
table(x)
quantile(x, .60)
quantile(x, .75)

There is no built in function for finding the range. The range() function will only give you the two values that are used in the calculation of the range: the maximum and minumum. To get the range from this, simply subtract the two values. One way of doing this is to use the diff() function. The interquartile range can be compute using the IQR() function. Be careful that the letters are capitalized as R is case sensitive so the function won't work with lowercase letters. The variance and standard deviation are calculated with the simple functions var() and sd(), respectively. There is no function in R for calculating the coefficient of variation so this must be done manually using the functions for mean and standard deviation.

diff(range(x))
IQR(x)
var(x)
sd(x)
sd(x) / mean(x) * 100

To compute skewness, one must first install and load the "moments" package. There is no built-in function for calculating z-scores so it must be done manually using the functions for mean and standard deviation. The covariance and corrrelation coefficient can be computed using the cov() and cor() functions, respectively. Remember that covarirance and correlation requires two variables, so you must input values for both an x-variable and y-variable. Then you must include both variables as argument in the functions.

library(moments)
skewness(x)
(x - mean(x)) / sd(x)
cov(x, y)
cor(x, y)
